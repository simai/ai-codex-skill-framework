# SIMAI Framework Fast Start

> Источник: github.com/simai/ui (README), github.com/simai/ui-source · Проверено: 2026-10-23 · Версия: ui-source aa81305b14f1, ui 3d9bf903a590

Use this file when the goal is simple and fast: connect SIMAI Framework, find a known pattern, assemble markup, and validate it without rediscovering the whole ecosystem.

## Fastest Working Route

1. Sync source repositories:

```bash
python3 skills/framework/scripts/sync_source_repos.py
```

2. If the task sounds like a documented utility/layout question, query docs atlas first:

```bash
python3 skills/framework/scripts/query_ui_doc_manifest.py \
  --manifest repo://ai-skill-framework/skills/framework/references/ui-doc-manifest.json \
  grid spacing button --limit 12
```

3. If the task sounds like "show me working markup", search `ui-play` examples first:

```bash
rg -n "sf-button|sf-input|<smart|sf-code" source/simai/ui-play/examples
```

4. Assemble the result from the narrowest layer:
  - utilities only for layout and spacing
  - shipped component classes when a static component is enough
  - smart-components only when orchestration/state/template loading is actually needed

5. Validate with strict checks:

```bash
python3 skills/framework/scripts/validate_framework_html_files.py --strict --catalog-strict /tmp/example.html
```

## Minimal Runtime Connection

For standalone HTML/testing, the pattern from the `simai/ui` README (checked
2026-10-23): pin a release commit, never `main`; `core.css` is linked by the
page; `sfPath` is set before `core.js`; Smart Components are found in
`distr/smart` under `sfPath` without extra configuration (`window.sfSmartPath`
only for pages that still serve the archived `simai/ui-smart`).

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/simai/ui@<release-commit>/distr/core/css/core.css">
<script>window.sfPath = 'https://cdn.jsdelivr.net/gh/simai/ui@<release-commit>/distr/';</script>
<script src="https://cdn.jsdelivr.net/gh/simai/ui@<release-commit>/distr/core/js/core.js"></script>
```

Utility classes are part of the current SIMAI Framework runtime. Load the
normal current runtime rather than a separate utility-only legacy bundle.

## Choosing Between Utilities, Components, And Smart Components

- Use utilities when the task is mostly layout, spacing, typography, colors, grid, or responsive behavior.
- Use shipped components from `simai/ui` when the task is presentational and the runtime can load a known component.
- Use smart-components only when the feature needs template orchestration, loader-managed initialization, or serialized props/events.

## Smart-Component Practical Notes

- Docs currently describe smart-components primarily through loader docs, not a full dedicated handbook.
- In docs, smart-components are inserted via `<smart ... />`.
- In vendor registries, many smart flows are also keyed by `sf-code`.
- In practice, verify both:
  - docs contract in `ui-doc`
  - real examples in `ui-play/examples/smart-components`
  - runtime existence in `ui/distr/smart`

## When To Escalate Beyond Fast Start

Switch from this file to deeper references when:

- the page is a full feature or multi-block layout
- loader behavior or cache invalidation matters
- custom smart orchestration is required
- naming/contracts must align with project-specific conventions
